# Launch Checklist

## Required before client approval

- [ ] Replace `YOUR_FORM_ID` in `contact.html` with the production Formspree ID.
- [ ] Submit a real enquiry and confirm delivery to `info@amplified.com`.
- [ ] Confirm every published price, package inclusion, cancellation term, and no-markup statement.
- [ ] Confirm the current team roster, titles, testimonials, client logos, and permission to publish them.
- [ ] Confirm the claims `287+ projects`, `126+ clients`, `$25K+ saved`, `35% of proceeds`, one-business-day response, and “East Africa's leading audio production studio.”
- [ ] Confirm copyright and usage rights for every portfolio image, stock image, client logo, testimonial, audio recording, and video.

## Vercel preview

- [ ] Import the repository into Vercel and use the repository root as the output directory.
- [ ] Confirm every clean URL, `.html` redirect, custom 404 page, and response header.
- [ ] Test the preview on current Chrome, Safari, Firefox, iOS Safari, and Android Chrome.
- [ ] Share the preview with the client and record approval.

## Host4Geeks production

- [ ] Back up the current production site and database before replacing files.
- [ ] Upload all repository files, including `.htaccess`, to the document root.
- [ ] Confirm Apache `mod_rewrite` and `mod_headers` are enabled.
- [ ] Confirm HTTPS is active and HTTP redirects to HTTPS.
- [ ] Verify canonical routes, legacy redirects, assets, embedded media, and the 404 page.
- [ ] Purge hosting/CDN caches after deployment.

## Discovery and measurement

- [ ] Add the approved analytics platform and verify consent requirements.
- [ ] Verify the domain in Google Search Console and Bing Webmaster Tools.
- [ ] Submit `https://amplifiedkreative.com/sitemap.xml`.
- [ ] Confirm `robots.txt`, canonical URLs, Open Graph previews, and structured data after launch.
- [ ] Monitor forms, crawl errors, uptime, and Core Web Vitals during the first week.
